ドローンの命令

    
Python とほぼ同じ書き方でドローンを動かします。▶ 実行すると上から順に1行ずつ動き、いま実行している行が黄色に光ります。関数の中を実行しているときは、呼び出し元の行が青で光ります。

    
ドローンを動かす（時間がかかる命令）

    

      
move(North)1マス動く。North(上)・East(右)・South(下)・West(左)。端をこえると反対側に出る

      
harvest()足もとの作物を収穫。育っていないと、こわれて何ももらえない

      
plant(Entities.Bush)足もとに植える。植えられたら True

      
till()耕す。草地 ⇔ 土 が入れかわる

      
use_item(Items.Water)足もとに水をまく。しばらく成長が速くなる

      
do_a_flip()宙返り（1秒）

      
print(...)コンソールに表示。ドローンもしゃべる

      
clear()畑を全部草地にもどして、ドローンを (0, 0) へ

    

    
調べる（すぐ終わる命令）

    

      
can_harvest()足もとが収穫できるなら True

      
get_entity_type()足もとの作物（Entities.Grass など）。何もなければ None

      
get_ground_type()Grounds.Grassland（草地）か Grounds.Soil（土）

      
get_pos_x() / get_pos_y()ドローンの位置。左下が (0, 0)

      
get_world_size()畑の一辺のマス数

      
get_water()足もとの水の量（0〜1）

      
num_items(Items.Hay)持っているアイテムの数

      
get_time()ゲーム内の経過時間（秒）

    

    
作物

    

      
Entities.Grass草地に自動で生える。収穫で 🌾干し草 ×1

      
Entities.Bushしげみ。🪵木材 ×1

      
Entities.Tree木。🪵木材 ×5。上下左右に木があると育つのが半分の速さ

      
Entities.Carrotニンジン。土にだけ植えられる。植えるのに 🪵1 と 🌾1。収穫で 🥕×2

      
Entities.Pumpkinカボチャ。土にだけ植えられる。植えるのに 🥕1。収穫で 🎃×3。ときどき枯れる（Entities.Dead_Pumpkin）

    

    
使える文法

    
if / elif / else、while、for x in ...、break、continue、def、return、global、and / or / not、リスト [1, 2]、タプル (1, 2)、辞書 {"a": 1}、x if 条件 else y

    関数：range len abs min max sum int float str list dict sorted round random、リストの .append .pop .insert .remove .index、辞書の .get .keys .values .items

    
キー操作

    
Tab で字下げ、Shift+Tab で戻す。Enter で次の行も同じ字下げ（: で終わる行のあとは1段ふかく）。Ctrl/⌘+Enter で実行。

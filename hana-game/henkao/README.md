# 変顔ボール

自分の変顔がボールになって、画面の中を跳ね回る幼児向けWebゲームです（仕様書 v0.1 の初期版＋外カメラ・ボール5こ対応）。

- `index.html` 1ファイルだけで動きます（外部ライブラリ・外部通信なし）
- 写真は端末内のメモリだけで処理し、サーバーへは送信しません。ページを閉じると消えます
- 保存されるのは「おとON/OFF」と「せってい」の値だけです（端末のlocalStorage）

## GitHub Pages での公開手順

1. GitHub で新しいリポジトリを作る（例：`henkao-ball`、Public）
2. `index.html` をアップロードする（「Add file」→「Upload files」）
3. 「Settings」→「Pages」→ Source を「Deploy from a branch」、Branch を `main` / `/(root)` にして Save
4. 1〜2分後に `https://<ユーザー名>.github.io/henkao-ball/` で遊べます

GitHub Pages は HTTPS なので、iPhone の Safari でもカメラが使えます。

## あそびかた

（ゲーム選択画面の中に置く場合は `henkao/index.html` として置きます。タイトルの「🏠 ゲームを えらぶ」で選択画面にもどれます）


1. 「📷 かおをとる」→ まるの中に顔を入れて 📸
2. ゆびで動かして顔をまんなかに →「⭐ これであそぶ」
3. 顔ボールが跳ね回ります。ボールをタップするとぴょーんと跳ねます
4. 「➕ ふやす」でもう1人の顔を撮って、ボールを5こまで増やせます（ボール同士もぶつかってぐにゃっとなります）
5. 「🔄 もういちど」で全部消して撮り直し

撮影画面右下の 🔁 で内カメラ／外カメラを切り替えられます（カメラが2つある端末のみ表示）。外カメラなら、大人が子どもの顔を撮れます。

カメラが使えないときは 🖼️ から端末の写真を選べます。「🙂 おためし」は写真なしで動きを確認できます。

## 調整

ゲーム画面の ⚙️ で「おもさ（重力）」「はずみ（反発係数）」「はやさ」「ぐにゃぐにゃ（変形の強さ）」を変えられます。
初期値は `index.html` 内の `DEFAULTS` で変更できます。

# のんびり島ぐらし（初期版・1島め）

ビルド不要の静的ブラウザゲーム。`index.html` / `style.css` / `game.js` の3ファイルだけで動きます。

## GitHub Pages で公開する手順

1. GitHub で新しいリポジトリを作る（例：`nonbiri-island`、Public）。
2. この3ファイル（＋README.md）をリポジトリ直下にアップロードする。
   - ブラウザから「Add file → Upload files」でドラッグ＆ドロップでOK。
3. リポジトリの **Settings → Pages** を開く。
4. 「Build and deployment」の Source を **Deploy from a branch** にし、Branch を **main / (root)** にして Save。
5. 1〜2分待つと `https://<ユーザー名>.github.io/nonbiri-island/` で遊べます。

iPhoneの Safari で開き「ホーム画面に追加」するとフルスクリーンのアプリ風に遊べます。

## 将来アプリ化するとき

全ファイルが相対パスの静的ファイルなので、そのまま Capacitor / Cordova / PWA（manifest + service worker を追加）でアプリ化できます。

## 調整したいとき

`game.js` の先頭にある `CONFIG`（各種秒数・上限・価格）、`ITEMS`（価格）、`BUILD`（施設の費用）、`GOALS`（チュートリアル目標と解放順）を書き換えるだけで、仕様書で未確定だった数値を変えられます。

セーブデータは localStorage の `nonbiri-island-v11` に保存されます。最初からやり直すには画面右上の ⚙️ を押してください。

## v0.2 の変更点（設計者フィードバック反映）
- 住居は棟数上限なし。市場は1×1になり、最初から建てられる（最初の目標）
- 幸福度 = 直近2分以内に市場から届いた商品の種類 ÷ 全商品の種類（%）。60%以上で人口増加
- 取り壊しは確認画面あり
- 最初の倉庫のスロットは「木材・石材・小麦・自動・自動」
- 道・広場・オフライン進行は廃止
- ⚙️ から「最初からやり直す」

## v0.3 の変更点（仕様破綻の指摘への回答を反映）
- 市場は無料で建てられる
- 住民の需要モデル：商品ごとに「消費時間」があり、届いた商品は100%→0%へ減る。30%を切った商品から配達、残りが少ない順、同率はランダム
- 幸福度の分母は「解放済み施設で作れる商品」
- 市場の販売商品は初期は空。倉庫スロットも初期は未設定（未設定には何も入らない）
- 目標に「倉庫スロット設定」「市場の販売商品設定」を追加、「幸福度60%」を「住民6人」より前に

## v0.4 の変更点（仕様変更依頼）
- 需要ゲージは家ごと。市場は「需要が30%を切った家×商品」のうち残りが少ない組から配達。幸福度は各家の「届いている商品の割合」の平均
- エリア開放は5×5単位（3×3=9エリア、初期は中央）。価格は100＋80×開放済み数（仮）
- 住居の上限：初期5棟、エリア開放ごとに＋5棟

## v0.5 の変更点（仕様変更依頼）
- 倉庫スロットごとに「確保」（最低保管量、初期20）。市場・生産施設への補充は確保分を残す。建築費用は確保分からも使える
- 採集範囲を周り8マス（3×3）に変更
- 住居上限はエリア開放ごとに+3（初期5）
- 井戸を追加（資源マス不要、枯れない）。水が需要・幸福度に入る

## v0.6 の変更点（仕様変更依頼）
- オフライン進行（最大12時間、おかえりなさい画面）と ⏩ 時間加速（×1/×2/×4）
- 初期マップ：住居1つだけ、資源は木のみ。倉庫も最初はない
- 目標チェーン：伐採所→井戸→倉庫→市場→下のエリア開放→採石場→小麦発見→製粉所→パン屋。エリア開放は目標4達成まで不可、最初は下のエリアのみ
- 新しい資源を含むエリアを開放すると、その採集施設（採石場・農場）が自動で解放
- 作業時間：原材料10秒/個。生産は材料の時間の合計（小麦粉20秒、板材・レンガ20秒、パン40秒）。パンは小麦粉2＋木材1（木材は火なので時間に加算しない）
- 倉庫の建築費はコインのみ（80）

## v0.7 の変更点（仕様変更依頼）
- 目標「販売で100コイン稼ぐ」を市場とエリア開放の間に追加
- **材料を取りに行くモデル**（`CONFIG.FETCH_MODE`。false にすると v0.6 の「毎分配分」に戻る）
  - 採集：10秒＋往復2秒＝12秒/個（井戸は往復なし）
  - 生産施設：足りない材料を、在庫のある最も近い場所（倉庫 or その材料をつくる施設）へ1回に「運べる数」だけ取りに行く。往復＝距離×2秒
  - 施設レベル：Lv1=1個、Lv2=2個（カゴ1＋50コイン）、Lv3=5個（台車1＋150コイン）
- 加工所（チュートリアル完了＝自由モードで解放）：レシピをコインで購入して選ぶ。カゴ（板材2、100コイン）、車輪（板材2、150）、台車（車輪2＋カゴ1、250）。道具は需要・幸福度に入らない

## v0.8 の変更点（設計者回答の反映）
- 目標：「販売で20コイン稼ぐ」→「住居を1つ建てる」（達成でエリア開放可）
- 倉庫は1棟10スロット、市場は販売枠10
- 道具（カゴ・車輪・台車）も商品として販売・需要・幸福度の対象に（レシピ購入後に解放）
- 確保の初期値0
- 住居の定員3人、人口増加の間隔3分
- 時間加速はテスト用（`CONFIG.DEBUG_SPEED=false` で非表示）

## v0.9 の変更点（設計者回答の反映）
- 人口：家に3種以上の商品が届いていれば「満足」。満足の家が60%以上で3分ごとに+1。定員4に戻す（幸福度の仕様は別途相談）
- 倉庫に作業員を置いて回収：施設の完成品棚から「最も多い施設（同数なら近い）」へ取りに行き、距離×2秒で倉庫へ。基本2個ずつ。30秒の自動搬送は廃止（`FETCH_MODE=false` なら従来どおり）
- 施設レベルは廃止。代わりに **カバン** を作業員に渡すと運べる数が +2/人（施設パネルの「カバン ＋－」。倉庫のカバン在庫から渡す。人を減らすと倉庫へ戻る）
- 新素材 **綿**（四隅のエリア）→ 綿花畑 → 機織り所（綿2→布 / 綿2→糸、レシピ切替）→ 加工所（カバン＝布1＋糸1、服＝布2＋糸1、レシピ購入100）。カゴ・車輪・台車は商品として残す
- 目標：パン5のあと「綿5 → 布と糸3ずつ → カバンのレシピ購入 → カバン1つ → 作業員に渡す」（全16個）。達成で自由モード
- 資源はエリアごとに「かたまり」2つ（6〜7マス）。中央は木、下は石、左右上は小麦＋木/石、四隅は綿＋何か
- 価格：水2、綿3、布・糸8、カバン24、服30（仮）

## v0.10 の変更点（搬送A案）
- 初期人口4
- 施設ごとに「搬送先：なし／倉庫／市場」。作業員の優先順は 作業 → 材料が無ければ取りに行く → 完成品が満杯（または作業できない）なら搬送先へ運ぶ
- 市場：配達が優先。配達できる商品が無ければ、倉庫か施設の棚へ仕入れに行く（毎分の自動補充は廃止）
- 倉庫：搬送先が倉庫の施設から回収が優先。無ければ市場や生産施設へ届ける
- 満足の条件は「3種」と「作れる商品の種類数」の小さい方（序盤は2種で満足）
- 消費時間を1.5倍（`CONSUME_MULT`）
- 目標：伐採所→井戸→市場（商品設定）→搬送先を市場に→20コイン→住居を建てて5人に→倉庫（スロット設定＋搬送先を倉庫）→下エリア→…（全17個）

## v0.11 の変更点（幸福度仕様）
- 需要ゲージは **住民ごと**。市場は（住民, 商品）単位で配達
- 個人幸福度 = 持っている（ゲージ>0の）アイテムの幸福ポイント合計 ÷ 分母 × 100、上限100、内部は小数保持
- 幸福ポイント：加工段階 0/1/2/3 で 1/2/3/4（`CONFIG.HAPPY_POINTS`）。同じアイテムは1回だけ
- 分母：解放済みの最大加工段階で 5/10/15/20（`CONFIG.HAPPY_DENOM`）。解放の瞬間に切替、下がらない
- 島全体 = 住民の個人幸福度の平均（内部は小数、表示は四捨五入）
- 新住民は幸福度0で加入、その瞬間に島全体を再計算、加入直後から配達対象
- 加工段階：木材・石・水・小麦・綿=0 / 木板・石材・小麦粉・糸=1 / 布・カゴ・車輪・カバン=2 / パン・服・台車=3
- ※人口増のしきい値を 60→35% に仮変更（序盤は水+木材=2pt/5=40%が上限のため）

# のんびり島ぐらし（初期版・1島め）

ビルド不要の静的ブラウザゲーム。`index.html` / `style.css` / `game.js` の3ファイルだけで動きます。

## GitHub Pages で公開する手順

1. GitHub で新しいリポジトリを作る（例：`nonbiri-island`、Public）。
2. この3ファイル（＋README.md）をリポジトリ直下にアップロードする。
   - ブラウザから「Add file → Upload files」でドラッグ＆ドロップでOK。
3. リポジトリの **Settings → Pages** を開く。
4. 「Build and deployment」の Source を **Deploy from a branch** にし、Branch を **main / (root)** にして Save。
5. 1〜2分待つと `https://<ユーザー名>.github.io/nonbiri-island/` で遊べます。

iPhoneの Safari で開き「ホーム画面に追加」するとフルスクリーンのアプリ風に遊べます。

## 将来アプリ化するとき

全ファイルが相対パスの静的ファイルなので、そのまま Capacitor / Cordova / PWA（manifest + service worker を追加）でアプリ化できます。

## 調整したいとき

`game.js` の先頭にある `CONFIG`（各種秒数・上限・価格）、`ITEMS`（価格）、`BUILD`（施設の費用）、`GOALS`（チュートリアル目標と解放順）を書き換えるだけで、仕様書で未確定だった数値を変えられます。

セーブデータは localStorage の `nonbiri-island-v6` に保存されます。最初からやり直すには画面右上の ⚙️ を押してください。

## v0.2 の変更点（設計者フィードバック反映）
- 住居は棟数上限なし。市場は1×1になり、最初から建てられる（最初の目標）
- 幸福度 = 直近2分以内に市場から届いた商品の種類 ÷ 全商品の種類（%）。60%以上で人口増加
- 取り壊しは確認画面あり
- 最初の倉庫のスロットは「木材・石材・小麦・自動・自動」
- 道・広場・オフライン進行は廃止
- ⚙️ から「最初からやり直す」

## v0.3 の変更点（仕様破綻の指摘への回答を反映）
- 市場は無料で建てられる
- 住民の需要モデル：商品ごとに「消費時間」があり、届いた商品は100%→0%へ減る。30%を切った商品から配達、残りが少ない順、同率はランダム
- 幸福度の分母は「解放済み施設で作れる商品」
- 市場の販売商品は初期は空。倉庫スロットも初期は未設定（未設定には何も入らない）
- 目標に「倉庫スロット設定」「市場の販売商品設定」を追加、「幸福度60%」を「住民6人」より前に

## v0.4 の変更点（仕様変更依頼）
- 需要ゲージは家ごと。市場は「需要が30%を切った家×商品」のうち残りが少ない組から配達。幸福度は各家の「届いている商品の割合」の平均
- エリア開放は5×5単位（3×3=9エリア、初期は中央）。価格は100＋80×開放済み数（仮）
- 住居の上限：初期5棟、エリア開放ごとに＋5棟

## v0.5 の変更点（仕様変更依頼）
- 倉庫スロットごとに「確保」（最低保管量、初期20）。市場・生産施設への補充は確保分を残す。建築費用は確保分からも使える
- 採集範囲を周り8マス（3×3）に変更
- 住居上限はエリア開放ごとに+3（初期5）
- 井戸を追加（資源マス不要、枯れない）。水が需要・幸福度に入る

## v0.6 の変更点（仕様変更依頼）
- オフライン進行（最大12時間、おかえりなさい画面）と ⏩ 時間加速（×1/×2/×4）
- 初期マップ：住居1つだけ、資源は木のみ。倉庫も最初はない
- 目標チェーン：伐採所→井戸→倉庫→市場→下のエリア開放→採石場→小麦発見→製粉所→パン屋。エリア開放は目標4達成まで不可、最初は下のエリアのみ
- 新しい資源を含むエリアを開放すると、その採集施設（採石場・農場）が自動で解放
- 作業時間：原材料10秒/個。生産は材料の時間の合計（小麦粉20秒、板材・レンガ20秒、パン40秒）。パンは小麦粉2＋木材1（木材は火なので時間に加算しない）
- 倉庫の建築費はコインのみ（80）

## 対応ブラウザ
- iOS 12 以降の Safari（iPad mini 2 / iPhone 5s 世代まで）、Android Chrome、PC の Chrome / Edge / Firefox / Safari
- Pointer Events が無い古い Safari（iOS 12 以前）ではタッチ／マウス操作に自動で切り替わります
